# CodeForge AI

### Autonomous AI Software Engineering Platform

CodeForge AI is a production-grade AI software engineering platform that can understand an existing codebase, plan software changes, generate code, execute tests in isolated environments, diagnose failures, repair code, perform security and governance reviews, and prepare GitHub Pull Requests for human approval.

> From repository understanding to tested, reviewed, and review-ready code.

---

## 🏗️ Architecture

![CodeForge AI Architecture](docs/images/codeforge-architecture.png)

CodeForge AI follows a layered architecture combining a React frontend, FastAPI backend, multi-agent AI orchestration, secure code execution, durable job processing, PostgreSQL with pgvector, GitHub integration, governance, analytics, webhooks, and disaster recovery.
